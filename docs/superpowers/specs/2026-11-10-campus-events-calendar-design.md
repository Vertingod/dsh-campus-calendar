# 大学生赛事与证书日历 DSH 插件设计

- 日期：2026-11-10
- 状态：设计已获用户批准，待文档复审
- 目标宿主：DSH 桌面客户端；插件遵循 DSH bundle + host/client 半片模式

## 1. 目标与边界

为中国大陆高校学生提供本地维护的竞赛、证书考试与关键节点日历。用户可以建立专业/年级/省份/关注方向档案，按适配度整理事项，使用日历、列表、筛选、收藏和提醒安排后续行动。

不实现在线抓取、自动实时更新或云端账号同步。系统不提供 OS 推送能力时，不声称发送系统通知；提醒仅作为插件内提醒标记展示。演示记录清楚标注“演示数据”，其名称和日期均不能被理解为真实、已核验的近期活动。

## 2. DSH 集成与模块边界

- `package.json` 声明 DSH bundle patch、client bundle、入口和构建/测试脚本。
- `cordis.patch.yml` 注册唯一插件 host entry，入口出现在宿主侧栏。
- Host half 注册 `/campus-calendar` 前缀 API，负责验证与读写本地数据文件、种子演示数据和 JSON 导入导出。
- Client half 为响应式单页界面；通过 API 读写状态，不直接承担权威存储逻辑。
- 领域模块单独负责事项 schema/校验、筛选/适配度、日期可信度呈现与 ICS 序列化，避免和 DOM/API 耦合。

主数据保存在 DSH 用户目录下的插件专属目录。JSON 导入按 schema 验证；错误项目逐项报错，不静默丢弃。采用原子文件替换，并处理文件损坏和写入失败的可见错误。无可用远端数据源时，适配器边界只定义本地仓储接口，不添加空壳抓取器。

## 3. 界面与主要交互

- 首次打开显示轻量档案设置：可搜索专业建议并自定义，填写年级、省份、多选关注方向及赛事/证书类型；可跳过非强制项并随后编辑。
- 桌面日历页默认月视图：标题/月份导航、月网格和近期节点并列；A 月历优先已由用户选择。提供列表切换。
- 窄屏隐藏侧栏为紧凑导航，月历与列表切换且事件行可横向无溢出地阅读；过滤器转为可访问的折叠面板。
- 搜索和筛选包括类别、适配专业、日期范围、报名状态、地区和“只看适合我”。无匹配结果时显示清晰空状态、清除筛选和调整条件入口。
- 详情展示名称、简介、适合人群、主办方、报名条件、关键节点、来源 URL、最近核验日期、备注、适配理由和可信度。来源缺失不得显示已核验。
- 数据维护支持新增/编辑/删除事项及 JSON 导入/导出；日历导出标准 ICS，遵守文本转义、CRLF、折行和无日期节点省略规则。
- 收藏与本地站内提醒偏好保存在用户数据中。提醒没有有效日期时不可设定，不会臆造日期。

## 4. 数据与可信度

事项包括稳定 ID、名称、类别、介绍、适配专业/方向、年级范围、地区、主办方、报名条件、来源 URL、最近核验时间、备注、报名状态及一个或多个日期节点。每节点记录节点类型、起止日期（可空）、日期精度和可信度状态。

可信度状态仅为：`official_confirmed`（有来源 URL 且核验时间有效）、`predicted`（必须注明推测依据/说明）、`pending_confirmation`（明确待确认说明）、`unknown`。日期未知为空值；渲染和 ICS 均不推导日期。演示记录另有 `demo: true`，始终展示演示标记且不得导出为“已核验”。

## 5. 错误处理、可访问性和隐私

所有写入 API 校验 payload 大小、类型、日期和 URL 格式；返回结构化错误。UI 提供加载状态、读/写失败反馈及重试，不覆盖用户编辑内容。使用语义按钮/表单标签、键盘可达的日期与对话框、可见焦点、状态文本和足够对比度；避免仅用颜色编码可信度。

档案与事项本地存储，不上传；来源 URL 仅作为可点击链接，不自动请求。JSON 导入大小设限，导出文件不包含运行时密钥或宿主身份数据。

## 6. 验收与测试

- 插件构建产物包含 host/client，bundle row 使 DSH 侧栏注册入口可发现。
- 领域测试覆盖筛选组合、个人适配评分、日期可信度 UI 标签/约束、无来源不可标 verified、演示标记，以及 ICS 日期与特殊字符正确转义。
- API 测试覆盖输入验证、损坏存储/读写错误和导入拒绝；保留错误记录的可读说明。
- 在桌面及窄屏浏览器验证首次设置、月历/列表切换、详情、事项维护、收藏/提醒、JSON 导入导出和 ICS 下载。
- 运行仓库测试与生产构建；记录命令和结果。当前工作区最初只有一份无关设计文档，不包含 Git 仓库、package.json 或现成测试命令；实现需建立独立最小 DSH 插件项目结构，且不得覆盖现存文档。

## 7. 明确未实现

真实活动日程、官方数据 API 接入、自动抓取/核验、云端同步、OS 通知及 DSH 账号关联都不在本版承诺范围内。接入真实记录必须人工提供来源 URL 和核验日期；本地示例不能作为真实活动日历使用。
